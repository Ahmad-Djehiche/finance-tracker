# finance-tracker

## Overview
Personal Finance and Subscription Tracker

The goal of this project is to implement a CLI that fulfills the following requriements:

1. Data Modeling: represent Transaction, Subscription
2. Data Management: FinanceManage store to manage records
3. User Interface: text based menu with the follownig functions:
    * add new one off transaction
    * add new recurring subscription
    * view all transactions/subscriptions for each month
    * view total spending by category
    * remove a subscription
